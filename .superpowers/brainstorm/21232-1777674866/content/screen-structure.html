Email + password. Biometric unlock on return visits.

🏠 Home Tab
📺
Home Feed
app/(tabs)/index.tsx
Live match banner, active tournaments, recent results, leaderboard preview.
🔴
Live Match View
app/match/[id].tsx
Real-time score, bracket position, team compositions, Riot API data feed.
🏆 Tournaments Tab
📋
Tournament List
app/(tabs)/tournaments.tsx
Open, active, and completed tournaments. Filter by prize pool, status.
🗂️
Tournament Detail + Bracket
app/tournament/[id].tsx
8-team bracket view, prize breakdown, entry fee, team slots, join button.
➕
Create Tournament
app/tournament/create.tsx
Captain-only. Set name, entry fee, start time. Auto-creates bracket when 8 teams join.
⚔️ My Team Tab
🛡️
Team Dashboard
app/(tabs)/team.tsx
Team name, roster (5 players), record, active tournament status. Create team if none.
📨
Invite / Join Team
app/team/invite.tsx
Share invite link or enter team code. Captain manages roster.
🎮
Match Lobby
app/team/lobby.tsx
Pre-match screen. Deep-link button to launch Wild Rift lobby. Countdown timer.
💰 Wallet Tab
💳
Wallet Overview
app/(tabs)/wallet.tsx
Balance, recent transactions, pending prize claims. Top up and withdraw buttons.
➕
Top Up
app/wallet/top-up.tsx
Stripe payment sheet. Add funds via card. Preset amounts ($5, $10, $25, custom).
🏦
Withdraw
app/wallet/withdraw.tsx
Stripe payout to bank account. KYC required first time. Min withdrawal $10.
👤 Profile Tab
🪪
Profile
app/(tabs)/profile.tsx
Avatar, Riot ID, stats (wins/losses/earnings), tournament history, settings.
⚙️
Settings
app/profile/settings.tsx
Notifications, linked Riot account, KYC status, log out.
