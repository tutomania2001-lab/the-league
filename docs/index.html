How It Works

From sign-up to champion

1
Create your account
Sign up with your email, link your Riot ID and set up your player profile with rank, avatar and stats.
2
Form or join a clan
Create a team, set your clan tag, invite friends or find teammates. Captains manage rosters and set clan privacy.
3
Top up your wallet
Add funds via Stripe. Captains can pay the full entry fee or split it across all 5 players automatically.
4
Enter a tournament
Browse open events, select your 5-player lineup and register. Your Wild Rift room code connects the lobby.
5
Play and get paid
Results are tracked live. Winners receive prize payouts directly to their wallet, withdrawable anytime.
◈ Riot Games Integration

Built for the Wild Rift ecosystem

The League is designed to integrate deeply with Riot Games APIs to provide verified match data, player rankings and live game tracking for competitive Wild Rift play.

  • Player identity verification via Riot ID
  • Match history and result validation
  • Live game data and score tracking
  • Rank-based matchmaking and seeding
  • Anti-fraud result verification

API Access Request

We are applying for Riot Games Developer API access to enable automated match result verification and live game data for our tournament platform. Our goal is to build the most trustworthy competitive Wild Rift experience available on mobile.
